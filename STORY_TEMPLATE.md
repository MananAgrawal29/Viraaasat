## Editorial checks
- [ ] Core thesis/question is clear.
- [ ] Claims are sourced and cross-checked.
- [ ] Data dates, units, methodology and limitations are stated.
- [ ] Conflicting evidence/perspectives are handled fairly.
- [ ] Headline and summary are accurate.
- [ ] Sensitive material reviewed.
- [ ] Visuals have alt text/captions/credits.
- [ ] Media rights verified.
- [ ] Citations/source notes prepared.

## Experience design
- [ ] Story layout is subject-driven, not generic.
- [ ] Motion supports the narrative.
- [ ] Mobile experience is intentionally designed.
- [ ] Reduced-motion and fallback states exist.
- [ ] Interaction is keyboard/touch accessible.
- [ ] Performance tested.

## Publish checklist
- [ ] Copy proofread.
- [ ] Fact-check complete.
- [ ] Links and citations verified.
- [ ] Responsive QA.
- [ ] Accessibility QA.
- [ ] SEO title/description/metadata.
- [ ] Credits and licenses complete.
- [ ] Final approval.
