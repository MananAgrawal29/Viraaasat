# Viraaasat

**India, in all its complexity.** *(working tagline; not formally locked)*

Viraaasat is a cinematic, editorial storytelling platform exploring India—its history, culture, people, geography, achievements, contradictions, failures, institutions, ideas, and future.

This folder contains the project's canonical context files. Read the relevant files before making changes.

## Context files
- `AGENTS.md` — instructions for AI coding agents and collaborators.
- `VISION.md` — project purpose, audience, principles, and scope.
- `DESIGN_SYSTEM.md` — brand identity, visual language, typography, color, motion.
- `ARCHITECTURE.md` — proposed technical direction and engineering principles.
- `EDITORIAL_GUIDELINES.md` — storytelling and writing standards.
- `SOURCES_AND_LICENSING.md` — research, citation, and media rights workflow.
- `STORY_TEMPLATE.md` — reusable planning structure for a weekly story.
- `AI_WORKFLOW.md` — single-agent workflow and tool handoffs.
- `ROADMAP.md` — milestones and priorities.
- `CHANGELOG.md` — meaningful project decisions and changes.

## Status conventions
- **LOCKED**: approved direction; do not change without explicit team decision.
- **PROPOSED**: recommended, awaiting implementation validation or team approval.
- **OPEN**: undecided.
- **DEPRECATED**: retained for historical context only.

When changing a locked decision, record the rationale and update the relevant file(s), then add an entry to `CHANGELOG.md`.
